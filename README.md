# Deck Editor

## 폴더 선택이 차단될 때

Chrome은 바탕화면, 문서, 다운로드 같은 폴더 **자체**를 프로젝트 폴더로 공유하지 못하게 할 수 있습니다. 이때는 **HTML 파일 직접 열기**를 눌러 `.html` 또는 `.htm` 파일을 선택하세요. 여러 파일을 한 번에 선택할 수 있고, 편집 후 각 원본 파일에 저장할 수 있습니다. 여러 HTML과 상대 경로 이미지·CSS를 함께 미리보려면 그 파일들이 들어 있는 **하위 프로젝트 폴더**를 만들어 해당 폴더를 선택하세요.

브라우저에서 HTML 장표의 문장을 클릭해 수정하고, 선택한 컴퓨터의 원본 HTML 파일에 저장하는 편집기입니다. 서버로 HTML 파일을 업로드하지 않습니다.

## 사용 방법

1. Chrome 또는 Edge에서 배포된 사이트를 엽니다.
2. HTML 한두 개를 편집할 때는 **HTML 파일 직접 열기**를 누릅니다. 프로젝트 전체를 둘러볼 때는 **프로젝트 폴더 선택**을 누릅니다.
3. 폴더 방식이라면 목록에서 HTML 파일을 고릅니다. 하위 폴더의 `.html`, `.htm` 파일도 검색됩니다.
4. 장표의 문장이나 왼쪽 문장 목록을 클릭해 수정합니다.
5. **원본에 저장** 또는 `Ctrl+S`를 누릅니다.

폴더는 각 컴퓨터에서 직접 선택합니다. 브라우저가 허용한 폴더 외의 파일에는 접근하지 않습니다. 저장 직전에 원본이 다른 프로그램에서 변경됐는지 검사합니다. 변경됐다면 덮어쓰지 않고 저장을 중단합니다.

**문장 편집** 모드에서는 문장 클릭을 편집기에 연결합니다. **장표 탐색** 모드에서는 장표의 원래 버튼과 링크를 사용할 수 있습니다. 저장할 때는 수정한 텍스트 구간만 교체하며 HTML 태그와 스타일, 스크립트는 그대로 둡니다.

## 실행 및 배포

```bash
npm install
npm run dev
```

Vercel에 이 GitHub 저장소를 연결하면 Vite 앱으로 빌드됩니다. 프로젝트 이름을 `dexteditor`로 지정하면 사용 가능한 경우 `dexteditor.vercel.app` 주소가 붙습니다. HTML 파일은 Vercel 서버에 저장되지 않습니다.

## 지원 범위

- File System Access API를 지원하는 최신 Chrome/Edge와 HTTPS(또는 localhost)가 필요합니다.
- UTF-8 HTML 파일을 대상으로 합니다.
- 같은 프로젝트 폴더 안의 상대 경로 이미지·CSS·스크립트는 미리보기에 함께 불러옵니다. CSS의 `@import`나 JavaScript 모듈의 상대 경로 import처럼 더 복잡한 참조는 표시되지 않을 수 있습니다.
- 장표 스크립트가 원본 문장 자체나 순서를 크게 바꾸면 해당 문장의 화면 연결이 제한될 수 있습니다.
